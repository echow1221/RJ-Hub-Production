# Editorial design refinement

## Reference access

The brief identified the UC Berkeley Othering & Belonging Institute as an editorial reference. An HTTPS read of its home and About pages through the workspace proxy returned CONNECT 403 on November 25, 2026, Pacific time. No page body or rendering was available to inspect. The refinement follows the editorial qualities identified in the brief and the supplied RJ Hub visual identity. [OBI home](https://belonging.berkeley.edu/) · [OBI About](https://belonging.berkeley.edu/about)

## Page hierarchy

- The homepage leads with the Hub's name, a short mission statement and two learning paths. The adjacent panel displays the selected archival photograph when the local review attachment is available. A brand-color circle and wave composition fills that space when there is no cleared photo.
- A concise introduction explains how restorative justice approaches harm. The selected resources identify each guide's type and practical use. The About pathway gives readers institutional context.
- Research and news have separate sections. Each appears once eligible published content exists, carrying category or date information appropriate to the collection. The homepage presents the remaining sections continuously when a collection is empty.
- The menu leads directly to About, What is RJ? and Resources. The linked Hub name returns to the homepage. An administrator can review the photo-led alternative and brand system in WordPress.

## Identity and editing

The six brand-kit palette colors, licensed Noto Serif heading type, Times New Roman prose and system sans interface remain. Crop and caption controls use native Image blocks and Media Library. Headings, buttons and resource cards use editable WordPress blocks. The optional collection sections use the RJ Hub Editorial Feed block, where staff can select the collection, adjust the heading and set the number of entries.

Before replacing the decorative panel with a public photo, use a cleared Media Library attachment, confirm the caption and attribution, and write alt text appropriate to the image's role. For private review, start the local environment with private media enabled on a new database volume.
