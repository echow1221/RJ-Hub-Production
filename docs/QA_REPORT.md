# Local validation report

Validated November 19, 2026, with WordPress 7.0.2, PHP 8.3.33, MariaDB 11.4.13, Docker Compose v2 and Chromium. The tests used independent local project databases for synthetic content and Editor changes. The local preview is restricted to loopback. The live Berkeley site received only read-only availability checks, which the environment proxy denied.

| Area | Result |
| --- | --- |
| Prototype installation | The loopback WordPress and MariaDB services became healthy. Private mode installed 17 editable pages, 2 original starter resources and 5 review-labeled attachments including the provisional logo. A fresh extraction of the prototype ZIP started independently, seeded 17 published pages and 2 resources, imported zero attachments and returned the expected resource listing. Repeating setup preserved existing site content. |
| Routes and content | Home, the alternate, About, What Is RJ, Blog, Projects, Resources, Maps, Offerings, Community Partners, Get Involved, Intake, Legacy, Contact, Accessibility, Privacy and Brand System returned HTTP 200. An unknown page returned HTTP 404. The browser checked the internal link graph. |
| Archives | Synthetic records exercised Blog and Resources search, categories, Blog tags, 12-plus-1 pagination, filter persistence and a direct article URL with the expected byline and publication date. The fixtures were confined to a separate stack. |
| Circular navigation | Desktop click and keyboard activation reached all six destinations. Touch layout exposed the pathways, and the linear alternative opened and linked to the same pages. |
| Responsive layout and accessibility | The main Chromium suite passed 108 checks. It covered 18 routes at 320, 390, 768 and 1440 CSS pixels with no page overflow, plus keyboard navigation, menu open/close and skip link behavior. Eight axe scans reported zero violations. Both homepage compositions were inspected at desktop width. The Gutenberg parser found zero invalid blocks in the Home, Alternate and Brand System pages. |
| Intake | The demo disclosed its status, accepted no input and initiated no submission or modification request during interaction. Local WordPress mail is disabled. |
| Map | The default catalog contained zero entries. The test stack displayed a complete approved fixture and withheld an unreviewed or incomplete fixture. The keyboard marker linked to its context and citation. The searchable text view worked with JavaScript disabled. Fixture data represents software checks. |
| Content import | Preflight and apply processed four synthetic records, creating two approved publications and two drafts. A second apply preserved all four. The approved sample retained its source URL, byline, publication and revision dates, tag and full test body. A bad body-file path failed preflight with no writes. Draft URLs returned 404 for anonymous requests. |
| Editor role | In an isolated browser session, an Editor published news, edited the homepage intro, replaced its hero through Media Library, published a resource with a source URL, changed the primary menu, and published a complete verified map fixture. The first attempt to publish the unverified map fixture was blocked. The Editor was denied access to user management. The changes were confirmed on the website and confined to the test stack. |
| Brand and photos | Reviewed all four brand pages and all 20 photos. The styles include all six exact brand colors. Noto Serif loaded in the browser under SIL OFL. The provisional mark was extracted from the supplied kit. Four private derivatives and the mark were verified, and original screenshots were excluded from the site and distributable package. |
| Code and configuration | PHP lint, JavaScript syntax, shell syntax, theme JSON parsing and Compose configuration validation passed. An initial bootstrap diagnostic exposed a disposable loopback administrator credential. The credential was rotated before validation and the installer was corrected to keep passwords out of setup output. |
| Backup | The database dump and uploads archive were generated, the SQL was nonempty and the tar contents could be listed. The ZIP includes a repeatable seed and import path. Backups are private because they can contain editor data, draft content and review media. |
