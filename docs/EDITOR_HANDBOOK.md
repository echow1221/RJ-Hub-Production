# RJ Hub editor handbook

Use your individual WordPress **Editor** account. Practice on the local site or in protected staging. An Administrator manages users, site-wide styles and templates. Use the dashboard to publish and revise ordinary content.

## Edit the homepage and core pages

1. Open **Pages → All Pages** and select **Home**, **About the RJ Hub**, **What Is Restorative Justice?**, or **Resources**. In the editor toolbar, open **Document Overview → List View** to find the section you want to change.
2. Edit a paragraph, heading, button or link directly in its block. For a link, select the label and use the link control to find the destination by title. Check what the link opens and use a descriptive label.
3. For the homepage image, use **List View → Homepage hero → Hero text and photograph → Hero photograph**. Select **Media Library** or **Upload** in an empty image block. To change a photograph, choose **Replace → Open Media Library** or **Upload**. Choose an image with publication clearance. Check **Alternative text** in the **Block** sidebar and revise the caption and credit below the image. Describe what matters to the reader. Leave the alternative text empty for decorative images.
4. Preview from the **View** menu at desktop and phone widths. Select **Save**, then reopen the page in a visitor tab and check what changed.

## Publish an approved article or resource

- **News.** Go to **Posts → Add Post**. Enter a title, add the full approved copy and set author, categories and an approved featured image in the **Post** sidebar. Use **Save draft** while awaiting review. Select **Publish** when ready. For scheduling, open the **Immediately** setting beside **Publish**, select the approved date and time, and confirm **Schedule**. Use the site's timezone.
- **Resources.** To change a featured resource card or introductory link, edit **Home** or **Resources** under **Pages**. To add a library entry, open **Resources → Add Resource**. Use the **RJ Hub details** panel for the source or approved PDF URL. Add a short description and select its category. Preview, publish after review, and check it appears in the library.
- **PDFs.** Use **Media → Add Media File** for an accessible document with publication clearance. Copy the file URL from its attachment details. Add a File block or paste the address into the appropriate PDF URL field. Check the link and make sure the PDF opens in a visitor tab.
- **Revisions.** Reopen an entry from its list. Select **Revisions** in settings when available, compare the copies, and restore the intended version. Recheck author, date, status, images and custom fields before saving.

Keep workbook rows with missing body text or uncertain approval in the migration inventory until the source and signoff are available. Keep archived services and historical relationships clearly labeled. The [migration report](CONTENT_MIGRATION_REPORT.md) records what is available for reconciliation.

## Change the primary menu

Open **Site Navigation**. Edit a **Link title** or **Destination**, use the **Order** field to sort links, and use the blank row to add an approved published page. Lower order numbers come first. Select **Remove** to take a link out of the menu. Select **Save navigation**, then test the desktop and mobile menus. For nested links or template changes, ask the site steward.

For **Blog & News** or **Research & Projects**, publish the approved individual posts or project entries first. Then find the matching archive page under **Pages → All Pages → Drafts**, preview it, and choose **Publish**. Published recent entries can appear on Home, and the archive link becomes available after you publish the archive. Add the archive to the primary menu if it belongs there. Follow the same page and menu steps for Contact or Get Involved only after the team confirms a maintained, working destination. Return an archive to draft and remove its menu link if every approved entry is withdrawn. Keep Maps, Offerings, Community Partners and Intake as drafts while their source material and permissions are under review.

## Run a 20-minute handoff

1. Sign in as an Editor on the test site. Find Pages, Posts, Resources, Media and Site Navigation.
2. Edit the home introduction and replace a test photo, then preview at two widths.
3. Prepare a draft article and a resource with a source link. Review the author, date, caption and category, then practice restoring a revision.
4. Change a practice navigation label and restore it. Find the review records and the people who approve updates in the [maintenance guide](MAINTENANCE_AND_OWNERSHIP.md).

Have the Administrator assign the incoming Editor's account through **Users → Add User**. Confirm the successor can complete these tasks and find the source, photo and migration records.
