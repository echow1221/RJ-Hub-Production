# RJ Hub editor handbook

Use the dashboard in your browser to edit the site. Start with an individual WordPress **Editor** account. Ask the site steward for the dashboard address and access if you need them. For practice, sign in to the local or protected test site. Check the address before publishing.

## Publish or schedule a Blog article

1. Go to **Posts → Add Post**. Type a headline and add the article in the editor. Use headings in order under the page title, starting with Heading 2 for main sections. Give source links meaningful names.
2. Open the **Post** settings sidebar. Under **Categories** and **Tags**, choose the terms a reader would search for. Use **Set featured image** to choose an approved image in the Media Library. Check its alternative text and preview the crop.
3. In the **Post** sidebar, select the correct **Author** if a byline is being preserved. Ask the managing editor about an unmatched source byline before publishing. Check the publication date, byline and attribution against the source.
4. Select **Save draft** during review and use the **View** menu to preview the finished article. For immediate publication, select **Publish** and confirm. To schedule, change **Publish** from its immediate setting to a future date and time, verify the site timezone with the managing editor, then select **Schedule** and confirm.
5. Reopen **Blog** in a visitor tab and check the article card, full article, category link and date. For a scheduled article, check the dashboard shows **Scheduled** and check the Blog again after it goes live.

## Update the home page

1. Go to **Pages → All Pages → Home → Edit**. At the top of the editor, open **Document Overview → List View** to find the blocks on the page. Select the section you want to edit and type in the highlighted block.
2. For the main photograph, select the **Image** block in the hero and choose **Replace → Open Media Library** or **Upload**. Select an approved image. In the **Block** sidebar, check **Alternative text**. Edit the caption below the image and check the crop at phone and desktop widths. Write a short description for a meaningful image and leave the alternative text empty for a purely decorative image. If you installed without preview photos, use List View to select the group containing the hero copy and buttons. Choose **Add after** in its options, insert an **Image** block, and enter `rj-hero-photo` in **Block → Advanced → Additional CSS class(es)** to apply the hero crop and layout.
3. To update a featured link, select its button or link text and use the link control to find an existing page by title. Check that the visible label describes where the link goes. Use **List View** to locate individual links in the circle navigation. Preserve their reading order and check the small-screen layout after changes.
4. Insert the **Editorial quotation** pattern from the block inserter's **Patterns** tab when you have approved wording and attribution. Keep the source and speaker visible. Update an existing quotation by selecting its Quote block.
5. Preview from the **View** menu, check text and image placement at two sizes, then **Save** or **Update** to publish an edit. Open the homepage in a second tab and test each changed link.

The alternate design is under **Pages → All Pages → Homepage Preview**. The current homepage setting is managed by an Administrator under **Settings → Reading**. Ask the steward to switch it if the team approves the alternate.

## Update the main navigation

1. In the dashboard sidebar, open **Site Navigation**.
2. Change the **Link title** or **Destination** in an existing row. Reorder links by changing **Order**, with lower numbers shown first. Select the **Remove** checkbox to hide a link. Add a published page using the blank row and its site path, such as `/about/`.
3. Select **Save navigation**, then visit the site and test the main menu on both desktop and mobile. Use Tab and Enter to confirm keyboard operation.

Ask a steward to handle nested navigation, site-wide templates and style changes in **Appearance → Editor**, including major header or footer design changes. Edit the content in the Contact, Accessibility and Privacy pages the same way as Home.

## Add or change structured content

Open the relevant dashboard section and choose **Add New**. Supply a clear title, a short summary and well-organized body blocks. Use the **Patterns** tab of the block inserter for a Scholarly project, Resource entry or Community partner profile. Set a featured image only when rights and context are documented. Open **RJ Hub details** in the **Post** settings sidebar for source fields and publishing requirements.

| Dashboard section | Information to check |
| --- | --- |
| **Projects** | Project authors, dates and context. Add a source URL or approved PDF URL and cite it in the body. |
| **Resources** | Resource category, short description and source or approved PDF. Explain what opens in the link text and mark PDF links. |
| **Community Partners** | Current relationship, name, description and approved link. Keep the entry as a draft until the relationship is verified and reviewed. |
| **Offerings** | Current status, intended audience and approved participation path. Keep unconfirmed services as drafts and describe legacy services on Legacy. |
| **Historical Map Entries** | Place, date or date range, nation or community context, coordinates and their uncertainty, source URL, PDF URL if available, brief context and a descriptive content warning. |

For a partner, offering or map entry, leave **Review status** at **Unreviewed** while evidence is being checked. Set it to **Verified** only after documented signoff. A historical map entry needs a source, place, date or date range and valid California coordinates before it can publish. Review dates and source references in the editor. Test the marker and its list alternative on the protected test site before approving publication. Use the title and text to preserve meaningful community names consistently.

To correct something, reopen the entry from its dashboard list, edit and preview, then save. To withdraw an item for review, switch it to draft. For an obsolete item, select **Move to Trash** and tell the managing editor whether an incoming link or redirect needs changing. The steward can assess any broken links or redirects before an item is permanently deleted.

## Media, PDFs and revisions

- **Edit a caption or credit.** Select the image in the page or article and edit the caption underneath. Add the approved credit and any date or context you can verify. Use **Media → Library** to edit an image's saved title, caption, description and alternative text for future inserts. Check existing page blocks separately because they can retain an earlier caption or alternative text.
- **Add a PDF.** Go to **Media → Add Media File**, upload the approved accessible PDF, and open its details to copy the file URL. Insert it with a **File** block or paste the URL into an appropriate **PDF URL** field. Verify it opens as a visitor and that the PDF itself is accessible and cleared. Keep private or unapproved documents in approved organizational storage.
- **Find and restore a draft.** Go to the content list and select **Drafts** to reopen it. For a previous version, open the item, select **Revisions** in its settings sidebar if available, compare versions and select **Restore This Revision**. Recheck settings such as status, author, attachments and custom fields after restoring.
- **Manage accounts.** Contact the steward for account changes. A WordPress Administrator opens **Users → Add User**, assigns **Editor**, and follows campus instructions for inviting the person. Use **Users → All Users** to review roles or remove access. Before removing someone, preserve their byline and transfer content ownership where appropriate. Editors continue to work through the content menus.

The Intake page lists the kinds of requests a future service might support, with an explicit closed status and no fields for visitors to submit. To edit the descriptive text, open **Pages → All Pages → Intake and Requests → Edit** and select the **RJ Hub Intake Preview** block. Route service changes through the owner, privacy reviewer and steward before making claims about the service or adding any form.

## 30-minute walkthrough

| Time | Practice |
| --- | --- |
| 0–5 min | Sign in as Editor, identify the test site and find Posts, Pages, Media, Site Navigation and the content menus. |
| 5–12 min | Draft a post, assign its author and category, insert a test image and practice setting a publication time. Preview and leave the practice entry as a draft. |
| 12–19 min | Change a copy of the homepage statement, replace its hero image, edit a caption and follow a featured link. Preview on desktop and phone. |
| 19–24 min | Prepare a resource with a PDF and a private map draft with a citation. Use the map list as a visitor. |
| 24–27 min | Change a practice navigation label and restore it. Compare a page revision. |
| 27–30 min | Find the style guide, migration report, photo usage report and contact blanks. Review who approves photos, partners, offerings and map entries. |

For a team training deck, capture four screenshots from the test site. Capture the Post sidebar with Author, Categories and Publish highlighted, the Home List View with the hero Image selected, the Site Navigation screen with a link and save button highlighted, and the map editor with the source and review fields highlighted. Use numbered callouts with descriptive text and keep account details and unpublished material out of screenshots.
