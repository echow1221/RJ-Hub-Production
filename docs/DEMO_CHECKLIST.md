# Local demo for Julie and Jordan

Run the prototype using [the setup instructions](../README.md). The paths below are on the running local site. Keep the demo within the review group while photo permissions and content are pending.

1. Open **Home** at `/` at desktop and phone widths. Read the mission section, review the image crop and caption, and follow the six links in the circle. Use Tab and Enter to follow the same paths with a keyboard.
2. Open the **alternate homepage** at `/home-alternate/` on both widths. Review the difference in reading order and how quickly you reach the navigation. The recommended default is the mission-led homepage because it introduces the Hub and restorative justice before offering a choice of pathways.
3. Open **Brand System** at `/style-guide/`. Compare colors, headline and body type, photo treatment and logo spacing with the supplied brand kit. Note any review flags on preview artwork.
4. Open **Blog**, **Projects** and **Resources**. Try the available search and filters. Review archive empty states when no approved entries are available. Open **Maps**, review the content warning and use the searchable list. Ask the managing editor which sources are ready for review.
5. Open **Offerings**, **Community Partners**, **Get Involved** and **Legacy**. Identify which claims can be supported now and which need written signoff. Open **Intake** and confirm the demo clearly communicates its unavailable status.
6. Sign in as a local **Editor**. In a test copy, edit the Home intro, replace the hero image with an approved test image, update a navigation label and prepare a news post and resource for review. Follow the [editor handbook](EDITOR_HANDBOOK.md).
7. Record the preferred homepage, photo and logo decisions, editorial changes and owners for the remaining source and launch reviews. Use the [content migration report](CONTENT_MIGRATION_REPORT.md), [photo usage report](PHOTO_USAGE_REPORT.md) and [Pantheon launch gates](PANTHEON_MIGRATION.md#launch-gates) to track those decisions.

Keep January 2027 as a tentative launch window until source reconciliation, the institutional review and a staging rehearsal are complete.
