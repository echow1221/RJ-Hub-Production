# RJ Hub Mac download

Download and extract this branch, then open its folder in Terminal and run `bash unlock.sh`. Enter the unlock key from your Codex chat at the prompt. The script verifies the decrypted file and saves `RJ_Hub_8092_Complete.zip` in the same folder.

Extract that complete ZIP. With Docker Desktop open, go into the resulting `RJ_Hub_8092_Complete` folder and run `bash start.sh`. The local site uses port 8092.
