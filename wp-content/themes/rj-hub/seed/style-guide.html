A practice of listening

Noto Serif is the licensed display substitute for Brixton. Times New Roman supports longer educational text and citations. The interface uses the system sans serif.

Use a block quotation for documented wording and add the verified source in the citation field.

Links, controls, and layout

Use descriptive links, one primary action per section, and visible keyboard focus. Use the page heading for the title and let subsequent headings follow a logical order.

Logo and photography

The combined circular brushstroke and RJ Hub lettering can be previewed in the header when local review media is enabled. The mark is extracted from the supplied PDF and is provisional pending an approved transparent master.

Keep generous clear space around the mark. For editorial photographs, write alt text for the scene, and use a caption for review status, credit and verified context.
