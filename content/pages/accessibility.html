Use the skip link at the beginning of each page to move directly to the main content. Pages can be read at different screen widths, and interactive controls can be reached with the keyboard.

Finding information

The main menu and site search are available from every page. The resource collection also offers a search field and category filter. Each guide has its own page so it can be read, shared, and revisited directly.

Keyboard navigation

Press Tab to move between links and controls, and Enter to open them. On smaller screens, use the menu button to show navigation links. Escape closes the menu and returns focus to the button.
