# RJ Hub — fresh Codex start

This kit is for a **new Codex chat and an empty project folder**. It does NOT depend on the missing previous Codex chat, files, or preview link.

1. Extract the ZIP into a NEW workspace folder (not into your old project unless you deliberately want to merge).
2. Ensure `AGENTS.md` sits at the root and `brand-kit/`, `references/`, and `assets/` appear alongside it.
3. Paste the entire content of `PASTE_THIS_INTO_CODEX.txt` into a new Codex task.
4. Codex should create installable WordPress code and a portable ZIP, not only a localhost address belonging to its private container.
5. Download Codex's output ZIP at the end. To preview on your own Ubuntu/WSL2 computer, follow its generated `README.md`.
6. Show Julie and Jordan the local prototype before anyone creates/pays for Pantheon or changes the existing live website.

`MASTER_CODEX_PROMPT.md` contains the complete project specification standalone for reading or manual pasting. `AGENTS.md` contains the original engineering working style plus this same specification.

**Important:** Writing `GPT-6.1` in AGENTS.md does not actually select the model. Set the model in Codex's model selector if that version is available.

**Photo use warning:** The supplied images are candidate assets and are not automatically cleared for public publication.
